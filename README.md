# Atualizações do Lumina Player

Canal de distribuição dos instaladores oficiais do Lumina Player para Android.

As versões são disponibilizadas em **Releases**. O aplicativo verifica o arquivo `latest.json`, baixa o instalador e confere sua integridade, pacote, versão e certificado antes de abrir a instalação do Android.

Listas M3U, credenciais, chaves privadas e dados dos usuários não fazem parte deste repositório.

A primeira versão com atualizador deve ser instalada manualmente sobre a versão anterior, sem desinstalar. As próximas podem ser obtidas pelo próprio aplicativo em **Perfil → Atualizações**.

Nenhuma lista, canal, conta de provedor ou assinatura acompanha o instalador.
